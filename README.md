# CMS page

The page display for WordPress and Drupal pages in the Cinatra artifact library: the package `@cinatra-ai/website-artifacts`. A page a run proposes to change is one drawing whichever system holds it, so both the WordPress and the Drupal extension draw their pages through this one package instead of a page display of their own. The package declares the page snapshot representation, a JSON document an agent extension files for the page it proposes to change.

Install from the Cinatra marketplace by searching for "CMS page" and clicking **Add**. No credentials or configuration are required.

## Works with

- Cinatra artifacts — library items filed as `application/json` by an agent extension
- The WordPress and the Drupal agent extensions, which file the page snapshot

## Capabilities

- Accept the page snapshot as a JSON document filed into the artifact library
- Install with no credentials, no configuration and no connector of its own
